# Q&A Translator

講義の質疑応答のための、日本語⇄英語の簡易リアルタイム翻訳チャット。
参加者はスマホで話す（または入力する）だけで、発言と訳がメッセージアプリのようにスクリーンに並びます。

- スクリーン用PC：`https://<ユーザー名>.github.io/<リポジトリ名>/?host`
- 参加者のスマホ：スクリーンに出るQRコードから（`?room=lecture` 付きのURL）

## 1. Firebase の準備（約10分・無料）

1. https://console.firebase.google.com で「プロジェクトを作成」（Google アナリティクスはオフで可）
2. 左メニュー「構築」→「Realtime Database」→「データベースを作成」
   - ロケーションはどれでも可（シンガポール `asia-southeast1` が近い）
   - 「テストモードで開始」を選択
3. 「ルール」タブを次に置き換えて「公開」

   ```json
   {
     "rules": {
       "rooms": {
         "$room": { ".read": true, ".write": true }
       }
     }
   }
   ```

4. 歯車アイコン →「プロジェクトの設定」→「マイアプリ」でウェブ（`</>`）を追加
5. 表示された `firebaseConfig` の中身を `config.js` に貼り付け（`databaseURL` が入っていることを確認）

※ Firebase の apiKey は公開されても問題ない種類のキーです。講義後はデータベースを削除するか、ルールの `true` を `false` にしておくと安心です。

## 2. GitHub Pages で公開

1. 新しいリポジトリを作り、このフォルダの5ファイルをアップロード
2. Settings → Pages → Branch を `main` / `root` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

## 3. スクリーン用PCの設定

`…/?host` を Chrome で開き、右上「設定」から：

- **この画面で翻訳を担当する**：オン（翻訳はこのPCがまとめて行います。`?host` を開くのは1台だけに）
- **Claude API キー**：入れると Claude で翻訳（文脈・用語集を考慮）。空なら Google 翻訳。キーはこのブラウザの中にだけ保存され、GitHub には載りません
- **講義の要旨・用語集**：講義の内容、キーワードの訳語、人名などを書いておくと、哲学的な質問の訳がかなり安定します
- 「翻訳テスト」で動作確認

画面右上のボタン：A−/A+（文字サイズ）、QR（QRコードの表示切替）、◐（明暗）、⛶（全画面）。
キーボードの `h` で下の入力欄を隠せます。PCのマイクで自分が話すこともできます。

## 4. 参加者の使い方

1. QRコードを読み取り、名前を入れて参加
2. 「日本語で話す」か「Speak English」をタップして話す
3. 話し終えたら「送信」→ 原文と訳がスクリーンとスマホに表示されます
4. 話すのが難しい場合は下の欄に文字で入力（言語は自動判定）

話している途中の文字も、スクリーン下部にリアルタイムで表示されます。

## 注意

- 音声認識は iPhone は Safari、Android/PC は Chrome で動きます（LINE などのアプリ内ブラウザでは動かないことがあります）
- 会場の Wi‑Fi が不安定な場合はモバイル通信で
- 別の部屋を使うときは `?host&room=test` のように部屋名を変えられます。本番前のテストは別の部屋で
- 会話を消すときは「設定」→「会話を全部消去」
